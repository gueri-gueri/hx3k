# Logos

HX3K's own logo: "HX" on a dark tile, "3K" on the primary blue, split along the slope of the X. Full color with its own ground, so the same file serves the dark and the light theme. Never recolor it or put it on a tile of your own.

- `hx3k-logo.svg` — The horizontal logo. The top of the menu at 32px tall, the splash at 44px. In the bundle: `Hx3kLogo`.
- `hx3k-mark.svg` — The square mark, edge to edge. The menu as a rail, at 36px. In the bundle: `Hx3kMark`.
- `app-icon.svg` — The mark inside the margin an operating system wants (824 of 1024). The source of the app's icon; not for use inside the interface.
- `app-icon.png` — The same, rendered at 1024px.

Colors inside the files: the tile runs `#27272a` to `#000000` with a `#3f3f46` hairline, the blue `#0000ff` to `#0000d0`, the letters `#ffffff`.
