# TONE3000

TONE3000's official logos, from its "TONE3000 Logos" pack, with every shape and color as it ships them. They are TONE3000's trademarks and are not covered by this system's license: use them only to say that something is, comes from, or is powered by TONE3000, as its API terms ask.

- `tone3000-logo.svg` — The full logo. Entry points and first exposure: the menu, "Powered by", the splash, the setup panel, the account row. 17 to 30px tall. In the bundle: `Tone3000Logo`.
- `t3k-mark.svg` — The compact mark. Only where the full logo has already been seen and there is no room for it: the Browse button, the origin marker on a converted capture, the menu as a rail. 9 to 14px tall. In the bundle: `T3KMark`.

Full color (red, blue, yellow) on any ground. Never recolored, stretched or cropped: set the height and let the width follow.
